# Структура проекта

## Основные модули

### `main.py`
Главный скрипт для запуска полного анализа логов. Объединяет все модули в единый конвейер обработки.

**Использование:**
```bash
python main.py --input data/logs.csv --output results/ --visualize --cluster
```

### `data_loader.py`
Модуль загрузки и предобработки логов безопасности.
- Поддержка CSV и JSON форматов
- Обработка временных меток
- Нормализация данных
- Обработка пропусков

### `feature_extractor.py`
Модуль извлечения признаков из логов.
- Временные признаки (час, день недели, выходные, ночное время)
- Частотные признаки (по IP, пользователям, типам событий)
- Статистические признаки
- Кодирование категориальных признаков
- Масштабирование признаков

### `anomaly_detector.py`
Модуль детекции аномалий с использованием алгоритмов машинного обучения.
- **Isolation Forest** - эффективный алгоритм для детекции аномалий
- **Local Outlier Factor (LOF)** - метод на основе локальной плотности
- **One-Class SVM** - метод опорных векторов для детекции выбросов
- Ансамбль методов для повышения точности

### `clustering.py`
Модуль кластеризации событий.
- **K-Means** - кластеризация на заданное количество кластеров
- **DBSCAN** - кластеризация с автоматическим определением числа кластеров
- Поиск оптимального числа кластеров
- Снижение размерности для визуализации (PCA)

### `visualizer.py`
Модуль визуализации результатов анализа.
- Временная линия событий с выделением аномалий
- Распределение аномалий по различным признакам
- Визуализация кластеров в 2D пространстве
- Корреляционная матрица признаков
- Сравнение алгоритмов детекции

### `report_generator.py`
Модуль генерации отчётов о выявленных аномалиях.
- HTML отчёт с детальной информацией
- CSV файл со списком аномалий
- JSON файл со статистикой
- Рекомендации по расследованию

### `evaluator.py`
Модуль оценки качества детекции аномалий.
- Метрики: Precision, Recall, F1-Score, Accuracy
- Матрица ошибок (Confusion Matrix)
- Сравнение нескольких алгоритмов
- Сохранение результатов сравнения

## Вспомогательные скрипты

### `generate_test_data.py`
Генерация синтетических данных для тестирования.
- Нормальные события (рабочие часы, будние дни)
- Брутфорс атака (множественные неудачные попытки входа)
- DDoS атака (аномально высокий трафик)
- Подозрительная активность (ночное время, нестандартные порты)

**Использование:**
```bash
python generate_test_data.py
```

### `test_anomaly_detection.py`
Скрипт для тестирования системы на данных с известными аномалиями.
- Оценка качества каждого алгоритма
- Сравнение алгоритмов
- Сохранение результатов сравнения

**Использование:**
```bash
python test_anomaly_detection.py --input data/test_logs.csv
```

## Алгоритмы машинного обучения

### Детекция аномалий:
1. **Isolation Forest** - изолирует аномалии через случайные деревья
2. **Local Outlier Factor** - определяет аномалии на основе локальной плотности
3. **One-Class SVM** - строит границу вокруг нормальных данных

### Кластеризация:
1. **K-Means** - разделение на заданное число кластеров
2. **DBSCAN** - кластеризация на основе плотности с автоматическим определением числа кластеров

## Метрики оценки

- **Precision (Точность)** - доля правильно выявленных аномалий среди всех выявленных
- **Recall (Полнота)** - доля правильно выявленных аномалий среди всех реальных аномалий
- **F1-Score** - гармоническое среднее Precision и Recall
- **Accuracy** - общая точность классификации
- **Specificity** - способность правильно идентифицировать нормальные события
